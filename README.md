## Lo que aprendi

- Una variable de entorno es un par nombre-valor que el sistema entrega a un programa cuando se ejecuta, para configurar su comportamiento sin cambiar el codigo.
- `.gitignore` indica a Git que archivos locales sin seguimiento debe omitir. No deja de rastrear archivos que ya fueron agregados.
- `git rm --cached` quita un archivo del indice de Git sin borrar la copia local.
- Una rama `feature` aisla un cambio. En un Pull Request se revisan los archivos modificados y su diff antes de integrar el cambio en `develop`.
